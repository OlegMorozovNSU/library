# Библиотека источников

Репозиторий с экспортом библиотеки Zotero и заметками по источникам. Используется статьями из репозитория `papers` (`../papers`). Правила и настройки экспорта: `README.md`.

## Правила для агента

- **`library.bib` не править руками**: он перезаписывается автоэкспортом Zotero, ручные правки пропадут. Исправления вносит автор в Zotero. Если запись содержит ошибку, опиши её автору (что именно, чем подтверждается).
- Новые источники предлагай автору списком (ключ, doi/arXiv-id, источник проверки). Сверку выполняет скил `bib-check` из репозитория `papers`.
- Заметки в `notes/` пиши по шаблону `notes/_template.md`, своими словами. Репозиторий **публичный**: без PDF, без цитат из текстов статей, без данных неопубликованных работ, без локальных путей и паролей.
- Ключи цитирования не меняй: на них ссылаются статьи.
- Коммиты и `git push` только по просьбе автора.
