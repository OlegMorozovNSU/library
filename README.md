# library

Библиотека источников для статей по численным методам в физике плазмы. Источник истины: **Zotero** автора; сюда попадает экспорт `library.bib` (Better BibTeX) и заметки по источникам. Статьи лежат в репозитории [papers](https://github.com/OlegMorozovNSU/papers) и берут отсюда записи.

> Репозиторий публичный. Здесь только библиографические метаданные и собственные заметки. **Не хранить PDF**, тексты статей, аннотации издателей и данные неопубликованных работ.

## Структура

| Путь | Что |
|---|---|
| `library.bib` | полный экспорт библиотеки; перезаписывается автоэкспортом Zotero, руками не править |
| `collections/` | экспорты отдельных коллекций Zotero (по теме или по статье), если нужны |
| `notes/` | заметки по источникам: `notes/<ключ>.md` по шаблону `notes/_template.md` |
| `scripts/commit-export.sh` | коммит обновлённого экспорта (`--push` отправляет в GitHub) |

## Настройка экспорта из Zotero

1. Установить плагин [Better BibTeX](https://retorque.re/zotero-better-bibtex/) (Zotero 7).
2. Формат ключей цитирования: `[auth:capitalize][year]` (получаются ключи вида `Chen2023`, как в статьях). При коллизии плагин добавит букву; ключи не менять после использования в статье.
3. В настройках Better BibTeX отключить экспорт путей к файлам и аннотаций: пропускаемые поля `file, abstract, note` (в `abstract` бывают тексты издателей, `file` содержит локальные пути).
4. Правый клик по библиотеке (или коллекции) → «Export Library…» → формат **Better BibTeX**, включить **Keep updated**, сохранить в `library.bib` (или `collections/<имя>.bib`) этого репозитория.
5. После изменений в Zotero: `scripts/commit-export.sh --push` (вручную или по расписанию).

Названия пунктов меню могут отличаться в версиях Zotero и плагина; ориентир: документация Better BibTeX (раздел Automatic export).

## Как использовать в статьях

Из `papers`: путь к клону записывается в `.local/paths.toml` (`[library] path`). Записи для статьи переносятся из `library.bib` в `<статья>/paper/references.bib` (только процитированные), после чего запускается проверка `bib-check`. Подробности: `papers/shared/library.md`.

## Правила

- Новый источник сначала добавляется в Zotero (кнопка «добавить по идентификатору»: DOI или arXiv-id), потом экспортируется.
- Запись сверяется с источником (название, год, первый автор, DOI) до использования в статье.
- Ключ цитирования после использования в статье не меняется.
